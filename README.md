# Phalano.github.io

  Projet d'idle / clicker game avec un arbre de compétences

## Ce qui a été ajouté:
  -Le systeme de sauvegarde de la session
  -L'arbre de compétences
    - Les regles de bases
    - Le système de casino
    - L'affichage
    - Les statistiques
    - Le système d'achat
    - Le système de compétences
    - Le casino
      - La roulette 
      - Le pile ou face
    - Le boost
      - L'apparition et disparition
      - L'effet
    - La génération passive
      - En ligne et hors ligne

## Organisation du projet
  - script2.js contient la structure du jeu (avec les outils, régles, affichage, etc...)
  - skills2.js contient les compétences dans l'arbre et leurs effets
  - style.css contient le style de la page
  - index.html est la page de base du projet

## Ce qu'il y a à rajouter
  - Plus de diversité dans les skills
  - Plus de choses à la fin
  - Plus de méchanique unique (ex: mini jeu de peche pour améliorer les gains)
